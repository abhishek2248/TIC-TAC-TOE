# **Tic-Tac-Toe Game Using Python**

## **1. Problem Statement**

The objective of this project is to develop a simple, interactive Tic-Tac-Toe game using Python. The game allows a human player to play against the computer on a 3 × 3 board. The system checks winning combinations, validates player moves, and identifies whether the game ends in a win or a draw.

## **2. Objectives**

- **Game Development:** Create an interactive Tic-Tac-Toe game using Python.
- **Board Design:** Display a 3 × 3 game board.
- **Player Interaction:** Allow the human player to select a position from 1 to 9.
- **Computer Opponent:** Use random selection to generate computer moves.
- **Win Detection:** Check horizontal, vertical, and diagonal winning combinations.
- **Input Validation:** Prevent invalid positions and moves on occupied cells.
- **Draw Detection:** Identify when all positions are filled without a winner.
- **Programming Practice:** Apply functions, loops, conditional statements, lists, and the random module.

## **3. Tools and Technologies**

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook
- **Python Module:** `random`
- **Data Structure:** Lists
- **Core Concepts:** Functions, loops, conditional statements, user input, and exception handling

## **4. Project Description**

This project implements a console-based Tic-Tac-Toe game in Python. The game board is represented using a list, where each position stores either an empty space or a player's symbol. The human player uses **O**, while the computer uses **X**.

The program displays the board and accepts the human player's position as input. It checks whether the selected position is valid and available before placing the symbol. The computer then selects an available position randomly.

After each move, the program checks for a winning combination or a draw. The game continues until either the human player or the computer wins, or all positions are occupied without a winner.

The project demonstrates the use of basic Python programming concepts to build a simple interactive game.

## **5. Expected Output**

- **Input:** The human player selects a board position from 1 to 9.
- **Process:** The program updates the board, generates computer moves, and checks the game status.
- **Output:** The updated game board and a message indicating the winner or a draw.

## **6. Conclusion**

The Tic-Tac-Toe project provides practical experience in Python programming and game logic. It demonstrates how lists, functions, loops, conditional statements, and random selection can be combined to create an interactive game.
